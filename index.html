Q1 Calculate the average temperature and rainfall using NumPy BL-3 (Application)

Answer: Use NumPy's mean() function to calculate the average temperature and rainfall from the available weather records. Express the results using appropriate units, such as degrees Celsius and millimetres.

NumPy Code (BL-3) 
import numpy as np

# Convert DataFrame series to NumPy arrays
temp_array = df['Temperature_C'].to_numpy()
rainfall_array = df['Rainfall_mm'].to_numpy()

# Calculate arithmetic averages ignoring missing NaN entries
avg_temp = np.nanmean(temp_array)
avg_rainfall = np.nanmean(rainfall_array)

print(f"Average Temperature: {avg_temp:.2f} °C")
print(f"Average Rainfall   : {avg_rainfall:.2f} mm")
Q2 Filter weather and crop yield data by region and season using Pandas BL-3 (Application)

Answer: Use Pandas filtering conditions to select records for specific regions, crop types, seasons, and years. This enables comparisons of weather conditions and crop yields across the selected groups.

Pandas Boolean Mask Filtering 
# Multi-variable boolean mask filtering
filtered_df = df[

# View subset records
print(filtered_df[['State', 'Year', 'Rainfall_mm', 'Temperature_C', 'Crop_Yield_Tonnes_Per_Hectare']])
Q3 Identify and impute missing weather readings and crop yield values BL-4 (Analysis)

Answer: Identify missing values using Pandas functions such as isnull() and isna(). Apply an appropriate imputation method, such as group-wise means, only when justified by the data and its context.

Imputation & Yield Derivation 
# Check missing observations count
print(df[['Rainfall_mm', 'Temperature_C', 'Production_Tonnes']].isnull().sum())

# Context-justified Season-wise Mean Imputation
df['Rainfall_mm'] = df.groupby('Season')['Rainfall_mm'].transform(lambda x: x.fillna(x.mean()))
df['Temperature_C'] = df.groupby('Season')['Temperature_C'].transform(lambda x: x.fillna(x.mean()))

# Derive crop yield following production/area verification
df['Crop_Yield_Tonnes_Per_Hectare'] = df['Production_Tonnes'] / df['Area_Hectares']
Q4 Group and analyze crop yield data by region and crop season to compare agricultural productivity BL-4 (Analysis)

Answer: Use Pandas groupby() to summarize crop yields by region, crop type, and season. Compare the summaries to identify differences in agricultural productivity across the available groups.

Pandas GroupBy & Aggregations 
# Regional and seasonal productivity summary
yield_summary = df.groupby(['State', 'Season']).agg(
    Mean_Yield=('Crop_Yield_Tonnes_Per_Hectare', 'mean'),
    Std_Yield=('Crop_Yield_Tonnes_Per_Hectare', 'std'),
    Avg_Rainfall=('Rainfall_mm', 'mean'),
    Observation_Count=('Crop_Yield_Tonnes_Per_Hectare', 'count')
).reset_index()

print(yield_summary.round(2))
Q5 Visualize the relationship between weather parameters and crop yields using Matplotlib and Seaborn plots BL-5 (Evaluation)

Answer: Create scatter plots to examine associations between rainfall, temperature, and crop yield, and line charts to compare trends over time. Use heatmaps or grouped bar charts where appropriate to explore regional and seasonal patterns.

Matplotlib & Seaborn Multi-plot 
import matplotlib.pyplot as plt

Academic Integrity & Exploratory Boundary Notes

1. Temperature Data Notice: Open rainfall tabular records do not inherently contain high-resolution daily temperature readings. Merging daily surface temperature requires high-resolution gridded IMD files (NetCDF/binary format). Where unavailable, rainfall is treated as the primary independent weather variable.

2. Non-Monocausal Attribution: This study is strictly framed as an exploratory empirical investigation to detect spatial-temporal correlations. Crop yields are determined by a combination of soil nutrient profiles, seed genetics, irrigation access, and pest pressures—weather alone does not determine harvest outcomes.
